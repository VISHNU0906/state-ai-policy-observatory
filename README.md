# State AI Policy Observatory

An evidence-led, reproducible tracker of AI-related state-government activity in India. Research window: 1 January 2024 to 10 November 2026. Six purposively selected states: Gujarat, Karnataka, Maharashtra, Tamil Nadu, Telangana, Uttar Pradesh.

This repository is being built in stages: research protocol, collection and normalization, reviewed evidence, dashboard, verification and release. Final instructions and limitations will be completed before release.

## Research contract

The unit is a state-government action or independently dated milestone, not an article. Include AI-specific policy, public finance, institutions, partnerships, public-sector deployments and governance safeguards. Exclude generic IT promotion, private investments without a state-government action, Union-only programmes and undated unsupported claims. Announced activity does not demonstrate implementation or impact.

Sources are discovered through web research, retrieved and reviewed by a human-in-the-loop evidence workflow, then transformed deterministically by the pipeline. A separate live collection command refreshes discovery candidates; it does not automatically publish unreviewed claims.

The state sample is purposive and English-web-heavy. Record counts are observations in this corpus, never state rankings or estimates of total activity.
