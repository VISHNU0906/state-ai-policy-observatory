# Design

Light, paper-like research workspace for daytime analysis. Restrained warm neutral surfaces, dark ink, deep terracotta for selected controls and links. System sans-serif for all interface text. Fixed type scale; compact metadata and generous readable evidence text.

Use OKLCH tokens, thin rules, table-like event rows and an inline expandable evidence panel. A state coverage sidebar and compact horizontal category bars orient the reader. No decorative hero metrics, gradients, shadows or repeated icon cards. Filter controls are native and labelled. Mobile stacks the sidebar above results.
